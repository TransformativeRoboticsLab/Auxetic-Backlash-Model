# RAD Primitive HTMLs

This folder is the quick entry point for the current browser-openable RAD
primitive simulations.

Open:

- `index.html` for the primitive launcher.
- `../web/one-cell-rotation/index.html` for the one-cell rotation primitive.
- `../web/two-cell-attachment/index.html` for the current three-cell
  no-backlash row primitive.
- `../web/index.html` for the main RAD digital workbench.

The primitive pages are static local HTML/JavaScript files and use the vendored
Three.js file at `../web/vendor/three.min.js`. They do not require a CDN.
