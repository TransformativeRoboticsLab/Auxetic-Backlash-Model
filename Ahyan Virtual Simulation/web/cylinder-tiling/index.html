This is a first-pass ring/cylinder primitive: each ring closes exactly by construction (n identical single-pin joints, turn angle 2*pi/n per joint - see the closure residual above), so the wheel diameter is derived from cell pitch and cell count, not chosen directly. It reuses the row primitive's single "A-B" pin relation only; it does not yet include the row's second mirrored pin, backlash dead-zone, or collision/clearance checking, and axial row-to-row attachment is a rigid z-offset copy rather than a solved joint. Extending those (double-pin joints, backlash-gated dilation limits, axial attach kinematics) is the natural next step before this becomes a fabrication-level wheel model.
